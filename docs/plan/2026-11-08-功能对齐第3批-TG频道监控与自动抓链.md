# 功能对齐第 3 批任务书：Telegram 频道监控与自动抓链转存

> 状态：待开工
> 目标：将原 CS 插件强大的 Telegram 频道消息监听、分享链接提取与自动匹配转存能力完整对齐到独立版。

---

## 1. 架构与业务链路

### 1.1 业务流程
1. **消息抽取**：
   - 从 Telegram 文本（包含正文、超链接、消息按钮）中正则抽取 115、夸克、阿里、百度等网盘分享链接以及提取码/密码。
   - 智能识别影视片名、季号、集号与画质标签（结合 P3 `domain.naming.parse_episode_from_name`）。
2. **订阅匹配与入库**：
   - 将抽取到的片名与库内正在追更的 `subscription` 清单比对。
   - 命中活跃订阅且属于当前缺失集数时：
     - 自动创建 `discovered_resource` 记录（score 赋予较高推荐度）
     - 若配置开启了「自动转存」，直接创建 `transfer_task` 并进入 `queued` 队列，由后台调度器全自动转存入库！
     - 若未开启自动转存，放入「待选资源」等待用户手动一键转存。
3. **消息测试与调试支持**：
   - 提供快速测试端点，用户可在界面粘贴一段真实的 TG 消息，实时返回提取出的片名、网盘类型、分享链接、密码以及匹配结果。

### 1.2 接口规范
- `POST /api/v1/tg/parse`：
  - 输入：`{"text": str, "extra_urls": list[str] = []}`
  - 响应：`{"title": str, "season": int | None, "episode": int | None, "links": [{"url": str, "provider": str, "password": str}], "matched_subscription_id": int | None}`
- `POST /api/v1/tg/ingest`：
  - 输入：`{"channel": str, "message_id": int | None, "text": str, "auto_transfer": bool = true}`
  - 响应：`{"ingested": bool, "resources_count": int, "tasks_created": list[int], "message": str}`
- `GET /api/v1/tg/status`：
  - 响应：`{"enabled": bool, "channels": list[str], "auto_transfer": bool, "ingested_count": int}`

### 1.3 前端交互（升级 `/radar` 搜索监控页面）
- **TG 频道监控板块**：
  - 监控频道列表卡片（如 `@Quark_Share_Group`、`@share115` 等），显示抓链状态
  - 自动转存开关：`收到频道新资源自动转存`
- **消息解析测试工具**：
  - 文本输入区域：支持直接粘贴一段 TG 消息文本
  - 点击「立即解析测试」
  - 下方实时以结构化 Badge 和卡片拆解展示：识别出的影视名称、季集、网盘服务商、链接、提取码以及是否命中我的追剧订阅！
