## 一、目标与非目标

**目标**：不依赖 MoviePilot 独立运行，覆盖「订阅基线 → 缺集计算 → 双源发现 → 转存 → 秒传 → 整理 → STRM → 媒体库回写」全链路，Web UI 可独立访问。

**非目标**：不替代 Emby/Jellyfin（只做客户端）；不做下载器（可选接 qBittorrent/Gopeed）；不做多租户。

## 二、分层与目录

```
csx-standalone/
├── backend/
│   ├── csx/
│   │   ├── domain/            # 纯领域模型与规则，零 IO、零框架依赖
│   │   │   ├── media.py       # MediaItem / Season / Episode / EpisodeKey
│   │   │   ├── subscription.py# 订阅、范围、质量偏好、缺集计算
│   │   │   ├── resource.py    # 候选资源、评分、去重键
│   │   │   ├── naming.py      # 命名模板引擎（替代 MP TransHandler）
│   │   │   └── task.py        # 任务状态机
│   │   ├── application/       # 用例编排，只依赖 domain + ports
│   │   │   ├── discover.py    # 双源发现
│   │   │   ├── transfer.py    # 转存
│   │   │   ├── organize.py    # 整理
│   │   │   ├── strm.py        # STRM
│   │   │   └── progress.py    # 进度表计算
│   │   ├── ports/             # 接口定义（Protocol）
│   │   ├── adapters/
│   │   │   ├── drive/         # 7 家网盘（继承）
│   │   │   ├── search/        # 14 个源（继承）
│   │   │   ├── notify/        # webhook / TG / 飞书
│   │   │   └── media/         # Emby / Jellyfin 客户端
│   │   ├── infra/             # db / scheduler / cache / config / logger
│   │   └── api/               # FastAPI 路由 + SSE
│   └── tests/
├── web/                       # Vue 3 + Vite + Tailwind 4 + shadcn-vue
└── docs/
```

**依赖方向铁律**：`api → application → domain`，`adapters` 只能被 `infra` 注入，`domain` 不许 import 任何外部包（除标准库）。

## 三、数据模型（SQLite + SQLAlchemy）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `media_item` | `tmdb_id`(uq), `type`, `title`, `year` | 剧/电影主档 |
| `season` | `media_id`, `season_number`, `episode_count` | 季 |
| `episode` | `season_id`, `episode_number`, `air_date` | 集（含未播） |
| `subscription` | `media_id`, `scope`(json), `quality_pref`, `state`, `source` | 订阅 |
| `discovered_resource` | `subscription_id`, `provider`, `share_url`, `dedup_key`, `score`, `state` | 候选池 |
| `transfer_task` | `idempotency_key`(uq), `state`, `attempt`, `next_retry_at`, `dead_letter` | 任务 |
| `library_file` | `episode_id`, `path`, `size`, `sha1`, `landed_verified` | 库内文件 |
| `strm_record` | `library_file_id`, `strm_path`, `generated_at` | STRM |
| `account` | `provider`, `credential`(加密), `quota_state` | 网盘账号 |
| `setting` | `key`(pk), `value`(json) | 配置（替代 226 个散键） |

**幂等键**：`idempotency_key = sha1(f"{provider}:{share_url}:{season}:{episode}:{quality_bucket}")`
**判重键**：以 `(media_id, season, episode)` 为身份，**不以文件名为判重键**（历史教训：命名即判重导致一集入库四五版）。

## 四、接口契约

资源式 REST，前缀 `/api/v1`：

| 资源 | 端点 |
|---|---|
| 订阅 | `GET/POST /subscriptions`、`PATCH/DELETE /subscriptions/{id}`、`POST /subscriptions/{id}/sync` |
| 进度表 | `GET /progress`、`GET /progress/{media_id}` |
| 候选池 | `GET /candidates`、`POST /candidates/{id}/accept`、`POST /candidates/{id}/ignore` |
| 任务 | `GET /tasks`、`POST /tasks/{id}/retry`、`POST /tasks/{id}/cancel` |
| 历史 | `GET /history`、`POST /history/retry_batch` |
| 媒体库 | `GET /library`、`GET /library/servers` |
| 配置 | `GET/PUT /settings`、`POST /settings/test/{provider}` |
| 诊断 | `GET /doctor` |
| 实时 | `GET /events`（SSE，替代现有 `/runtime/stream`） |

**响应包络统一**：`{"ok": bool, "data": ..., "error": {"code","message","hint"}}`。
**错误码**：沿用现有四类（`SHARE_EXPIRED` / `NO_MATCH` / `RAPID_MISS` / `QUOTA_EXCEEDED`），新增 `PROVIDER_AUTH` / `MEDIA_UNREACHABLE`。

## 五、任务状态机与失败回滚

```
queued → running → succeeded
              ├→ retry_wait → running   (60/120/240s 退避，上限 30 分钟)
              └→ failed → dead_letter   (需用户显式重试)
```

- **每次状态迁移先写库再执行**，崩溃后可恢复（不接受"内存里计数"）。
- **转存失败回滚**：已上传的部分文件按 `library_file` 记录逐个删除，删不掉记 `residue` 表等人工清理。
- **整理失败不回滚转存**：转存成功即落库，整理失败重试，不影响文件存在性。

## 六、并发与限流

| 维度 | 策略 |
|---|---|
| 网盘账号 | 每账号令牌桶（115：4 并发；夸克：8；其余默认 4），可配置 |
| 同文件 | 按 `sha1` 串行，避免同源并发互删 |
| 同订阅 | 按 `subscription_id` 串行，避免同一集重复转存 |
| 全局 | 任务队列最大并发 8，超出的排队而非丢弃 |
| 外部 API | TMDB / Emby 各一个令牌桶 + 缓存（TMDB 24h，Emby 60s） |

## 七、前端架构

### 7.1 页面（照 `csx-console/` 已设计的 IA，10 页）

| 路由 | 页面 | 核心内容 |
|---|---|---|
| `/` | 总览 | 5 步流水线、追更健康度、缺口排行、双源实时、执行中 |
| `/progress` | 追更进度表 | 基准 / 库内 / 缺口区间 / 下一集 / 双源状态，展开看逐集矩阵 |
| `/baseline` | 基准面 | 订阅列表、TMDB 播出日历、逐集对齐、同步日志 |
| `/radar` | 双源雷达 | 主动搜索（定时/来源健康）+ TG 频道（监听/命中流） |
| `/candidates` | 候选池 | 去重、打分、与库内对比、采用/忽略 |
| `/tasks` | 执行队列 | 取链 → 下载 → 秒传 → 入库 → STRM → 回写 |
| `/history` | 转存流水 | 按媒体聚合、失败原因、批量重试 |
| `/media` | 媒体库 | Emby 库概览、继续观看、最近入库、库体检 |
| `/settings` | 设置 | 分 6 组（基准面/双源/转存洗版/STRM/通知/高级），替代现在 226 键平铺 |
| `/search` | 手动搜索 | 指定标题多源并发检索 |

### 7.2 组件分层

```
web/src/
├── components/ui/        # shadcn-vue 复制进来的原子组件（可改）
├── components/domain/    # 业务组件（MediaCard / EpisodeMatrix / TaskRow）
├── pages/                # 10 个页面
├── composables/          # 数据与状态（TanStack Query 封装）
├── lib/api.ts            # 统一 fetch 封装（包络解包、错误提示）
└── styles/theme.css      # Tailwind v4 主题变量
```

**禁止**：页面里写 `<style scoped>` 手写 CSS（现有 9,565 行就是这么来的）；一律用 Tailwind 原子类 + 主题变量。

### 7.3 鉴权

单用户密码 → `POST /auth/login` 发 HttpOnly cookie session；前端 401 时跳登录页；SSE 走同源 cookie。

## 十、禁止事项

1. 不许 import 任何 `app.*`（MoviePilot 模块）——CI 加一条 grep 门禁。
2. 不许复制 MoviePilot / Alist / AGPL 项目的源码。
3. 不许在页面里写手写 CSS 覆盖组件库样式。
4. 不许把 226 个配置键原样搬过来——必须归组到 6 个 section。
5. 不许用文件名做判重键。
6. 需求变更先改本文档，再改代码。
