## 0. 本阶段目标（一句话）

基于 `csx-console/` 已冻结的 10 页 IA 与「5 步流水线」信息架构，用 **Vue 3 + Tailwind 4 + shadcn-vue 规范 + @lucide/vue** 完整构建 10 个业务页面、全局侧边栏/顶部栏布局、SSE 实时联动与 API 全量对接，彻底终结 MoviePilot 旧版杂乱的前端体验。

## 2. 界面与设计铁律（严格照架构规范）

1. **零硬编码裸颜色**：所有颜色必须使用 `src/styles/theme.css` 定义的语义化 tokens（如 `bg-surface`, `border-border`, `text-fg`, `text-muted`, `bg-primary`, `bg-status-*`），禁止手写 hex/rgb 颜色。
2. **移动端触控友好**：所有按钮、切换器、导航项的最小触控面积不小于 **44 × 44px**（`min-h-[44px] min-w-[44px]` 或配套 padding），在 375px 窄屏视口下无横向溢出滚动条。
3. **响应式侧边栏**：
   - 桌面端（`>=1024px`）：固定左侧 240px 导航栏，收拢与展开功能。
   - 移动端（`<1024px`）：顶部汉堡菜单触发滑动抽屉。
4. **SSE 实时状态指示**：顶部栏必须带有实时连接指示灯（绿点：已连接；黄点：重连中），收到 `task_status` 事件时局部更新任务数与卡片状态，不整页重载。

## 6. 禁止事项

1. 严禁使用任何 `vuetify` 相关代码与类名。
2. 严禁在页面写手写 CSS 覆盖组件样式，必须全靠 Tailwind utility classes。
3. 严禁使用未声明的全局状态库，采用 Vue 3 原生 `ref/reactive` 与 composables。
4. 严禁跳过页面做假骨架，10 个页面必须均具备真实数据呈现与操作交互。
5. 严禁删除现有 `LoginPage.vue` 的认证逻辑。
