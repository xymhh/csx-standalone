# 功能补全第 1 批任务书：高频交互三件套（目录树选择 + 手动转存 + 剧集抽屉）

> 状态：待开工
> 目标：将原 CS 插件最核心的高频业务交互迁移并重塑为现代 Zinc 风格组件，彻底解决手打路径难、无手动转存入口、看不了剧集真实文件明细的三大痛点。

---

## 1. 详细规格与文件落点

### 1.1 网盘目录树选择器 (`DirectorySelectDialog.vue`)
- **后端适配与接口**：
  - 在 `csx/ports/drive.py` 扩充 `list_directories(parent_id: str = "") -> list[CloudDirectory]`（若已有 `list_dir` 则复用或适配）
  - 驱动适配器 `csx/adapters/drive/quark.py` 和 `p115.py` 实现列出子文件夹能力
  - 暴露接口 `GET /api/v1/drives/{account_id}/folders`（参数 `parent_id` 默认为根，返回 `[{"id": str, "name": str, "path": str, "has_children": bool}]`）
- **前端组件 `components/dialogs/DirectorySelectDialog.vue`**：
  - 弹窗展示树形文件夹结构，点击文件夹左侧箭头异步加载子文件夹
  - 支持选中当前文件夹，点击「确认选择」，将所选路径回填至调用方
  - 在 `SettingsPage.vue` 的「网盘转存保存目录」和「本地挂载根路径」旁增加「📂 浏览网盘」按钮。

### 1.2 手动贴链接转存弹窗 (`ManualTransferDialog.vue`)
- **后端接口**：
  - `POST /api/v1/drives/share/inspect`：
    - 输入：`{"provider": "115"|"quark"|"auto", "share_url": str, "password": str = ""}`
    - 响应：`{"provider": str, "share_title": str, "files": [{"id": str, "name": str, "size": int, "is_dir": bool}]}`
  - `POST /api/v1/drives/share/transfer`：
    - 输入：`{"account_id": int, "share_url": str, "password": str, "file_ids": list[str], "target_dir": str, "media_id": int | None = None}`
    - 响应：创建一条 `transfer_task` 并进入 `queued`，返回任务 ID 与状态。
- **前端交互**：
  - 顶栏 `Topbar.vue` 增加显著按钮 **「+ 快捷转存」**（白底黑字反转）
  - 点击弹出 Dialog：
    - 输入网盘分享链接与密码，点击「解析分享」
    - 列表展示分享内包含的文件（文件名、大小），支持全选/单选
    - 选择转存目标网盘账号与目标目录（可结合目录树选择）
    - 点击「确认转存」，触发任务并提示「转存任务已提交，可在转存队列查看进度」。

### 1.3 剧集详情侧滑大抽屉 (`MediaDrawer.vue`)
- **后端接口**：
  - 扩充 `GET /api/v1/progress/{media_id}`，确保返回媒体的完整元数据（TMDB 评分、海报图片路径、首播年份、剧情简介）以及每集的入库文件详情（文件 ID、路径、大小、画质标签 `quality_bucket`、入库时间）
- **前端组件 `components/domain/MediaDrawer.vue`**：
  - 右侧平滑滑出的 Sheet 抽屉（宽度 `w-full max-w-2xl`，带毛玻璃遮罩）
  - **头部海报区**：TMDB 海报、标题、首播年份、类型标签、简介文字
  - **季选项卡**：第 1 季、第 2 季...
  - **逐集明细表**：
    - 集号、集名、播出日期
    - 入库文件完整网盘路径（可点击复制）、文件大小（GB）、画质徽章（[REMUX] / [4K HDR] / [1080p] 等）
    - 缺失状态以温和珊瑚红标明「待转存」
    - 单集快捷操作：「立即找源」按钮。
- 在 `ProgressPage.vue` 和 `DashboardPage.vue` 的媒体项上支持点击弹开该抽屉。
