# 功能补全第 2 批任务书：302 直链播放重定向 + 网盘全盘整理 + 重复版本查重

> 状态：待开工
> 目标：实现基于 302 重定向的网盘原画直链播放（Emby 秒开且不占服务器带宽），以及网盘暂存区全盘扫描整理与重复文件清理治理。

---

## 1. 详细架构与接口规范

### 1.1 302 直链播放服务 (`csx/api/routes/stream.py`)
- **端点**：
  - `GET /api/v1/stream/redirect`：
    - 参数：`file_id: int`（`library_file.id`），可选 `token: str`
    - 逻辑：
      1. 根据 `file_id` 读取 `library_file` 记录，获取关联的网盘类型 `provider`、文件路径 `path` 与 `sha1`
      2. 检查内存直链 LRU 缓存（TTL 45 分钟，key 为 `file_id:user_agent`），若命中且未过期直接 302
      3. 未命中时调用对应账号驱动的 `resolve_download_link`（115 或夸克官方高速下载 URL）
      4. 写入内存缓存，返回 HTTP 302 Found 重定向到网盘真实下载流地址！
- **STRM 联动**：
  - `application/strm.py` 的 `mode` 增加 `direct_302`（或在 template 中支持自动拼装 `http://{host}/api/v1/stream/redirect?file_id={library_file_id}`），Emby / 播放器读取此 `.strm` 文件即可实现原画直连网盘播放。

### 1.2 网盘全盘/暂存区整理 (`csx/application/organize_scan.py`)
- **业务流程**：
  - 用户指定源目录（默认如 `/CSX/_inbox` 或自定义网盘目录）
  - 扫描该目录下的所有视频与字幕文件
  - 使用 `domain/naming.py` 识别片名、季集，匹配库内 `MediaItem`，计算出标准目标路径
  - 接口分两步（安全可控）：
    - **扫描预览**：`POST /api/v1/organize/scan`，返回匹配成功的条目列表（源路径、识别片名、季集、目标路径）与未识别文件
    - **确认执行**：`POST /api/v1/organize/execute`，批量执行 `DrivePort.move` + `DrivePort.rename` 归位，更新 `library_file` 记录，清理空文件夹。

### 1.3 重复文件/多版本查重与清理 (`csx/api/routes/duplicate.py`)
- **端点**：
  - `GET /api/v1/library/duplicates`：
    - 查询同一 `(media_id, season, episode)` 对应多条 `library_file` 记录的组
    - 按画质阶梯（`remux > dv > hdr > 4k > hd > sd`）自动标记推荐保留项，其余标记为待清理
  - `POST /api/v1/library/duplicates/clean`：
    - 入参：`{"library_file_ids": [int, ...]}`
    - 逻辑：删除指定的冗余 `library_file` 记录，同时异步调用对应网盘驱动删除该文件，释放网盘空间。

### 1.4 前端界面交互 (`web/src/pages/MediaPage.vue`)
- 在「媒体库」页面上方增加分栏：
  - **已入库影视列表**（原有视图）
  - **网盘扫描整理**：选择网盘账号与源目录（带「📂 浏览」选择树）→ 点击「扫描未整理文件」→ 表格展示预览（源路径 → 目标路径）→ 点击「一键执行整理归位」
  - **重复版本查重**：展示多版本重复列表，高亮画质对比，带「一键清理冗余副本」按钮。
