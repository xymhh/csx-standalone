# 重命名规则设计（对齐 MoviePilot 方案）2026-11-09

> 状态：设计待确认，未开始编码。
> 目标：把 CSX 写死的命名格式（`片名 (年份)/Season 01/片名 (年份) S01E01 [REMUX].mkv`）
> 换成 MoviePilot 那套 **Jinja2 模板 + 变量** 的方案，用户可自定义电影/剧集两条模板。

## 1. MoviePilot 的实际做法（已读源码确认，非凭印象）

| 事实 | 出处 |
| --- | --- |
| 模板是 **Jinja2 字符串**，`/` 划分目录层级，最后一段是文件名 | `app/modules/filemanager/transhandler.py` → `TemplateHelper().render(template_type="string")` |
| 电影、剧集各一条模板，存在配置 `MOVIE_RENAME_FORMAT` / `TV_RENAME_FORMAT` | `app/core/config.py:397-409` |
| 默认电影模板 | `{{title}}{% if year %} ({{year}}){% endif %}/{{title}}{% if year %} ({{year}}){% endif %}{% if part %}-{{part}}{% endif %}{% if videoFormat %} - {{videoFormat}}{% endif %}{{fileExt}}` |
| 默认剧集模板 | `{{title}}{% if year %} ({{year}}){% endif %}/Season {{season}}/{{title}} - {{season_episode}}{% if part %}-{{part}}{% endif %}{% if episode %} - 第 {{episode}} 集{% endif %}{{fileExt}}` |
| `{{fileExt}}` 自带点号（`.mkv`） | `transhandler.py:359` `file_ext=f".{fileitem.extension}"` |
| 变量由 `TemplateContextBuilder` 装配，未定义变量渲染为空串 | `app/helper/message.py:30-320` |
| 字幕跟随视频改名，并按语言加 `.zh-cn` / `.default` 后缀 | `transhandler.py::__rename_subtitles`、`tests/test_subtitle_rename.py` |

## 2. CSX 的变量清单

### 第一版能真实提供的

| 变量 | 含义 | 来源 |
| --- | --- | --- |
| `title` | 中文标题 | `media_item.title` |
| `year` | 年份 | `media_item.year` |
| `title_year` | `片名 (年份)` | 拼接 |
| `type` | `电影` / `电视剧` | `media_item.type` |
| `tmdbid` | TMDB ID | `media_item.tmdb_id` |
| `season` | 季号数字（1） | 任务/文件行 |
| `season_fmt` | `S01` | 格式化 |
| `season_episode` | `S01E01` | 格式化 |
| `episode` | 集号数字（1）；多集 `1-3` | 文件行 |
| `total_episodes` | 本季总集数 | 可查 `season` 表 |
| `episode_title` | 单集标题 | `episode.title`（可能为空） |
| `episode_date` | 播出日期 | `episode.air_date` |
| `fileExt` | `.mkv`（含点） | 原文件后缀 |
| `videoFormat` | `2160p` / `1080p` / `720p` / 空 | `quality_bucket` 映射（`4k`→`2160p`） |

### 第一版留空（模板里 `{% if %}` 会自动消失，不会产生脏字符）

`en_title`、`original_title`、`actors`、`overview`、`vote_average`、`poster`、`backdrop`、
`imdbid`、`doubanid`、`bangumiid`、`anilistid`、`part`、`edition`、`effect`、
`resourceType`、`resource_term`、`releaseGroup`、`videoCodec`、`videoBit`、`audioCodec`、`webSource`、`fps`。

> 说明：这些需要额外解析资源标题或扩展 TMDB 字段。第一版如实留空，比"填个假值"更安全；
> 想补齐可在 P3 逐个加解析器。

## 3. 存储与接口

- 配置分组 `naming`（复用现有 `Setting` 表 + `/api/v1/settings/{section}`）：
  - `movie_format`、`tv_format`、`variety_format`（默认同 tv）
  - 值为**原始模板字符串**，不转义
- 新接口：
  - `GET /api/v1/naming` → 当前模板 + 官方默认模板（供「恢复默认」）
  - `PUT /api/v1/naming` → 保存前校验，失败返回 400 + 具体原因
  - `POST /api/v1/naming/preview` → 入参 `{media_id | 示例数据, season, episode, extension, quality_bucket, template?}`，出参 `{path, warnings}`，**只渲染不落盘**，供设置页实时预览
  - `GET /api/v1/naming/variables` → 变量名/说明/示例值/是否可用

## 4. 渲染与校验（比 MP 多做的几道闸）

1. `jinja2.sandbox.SandboxedEnvironment` + `ChainableUndefined`：禁止属性穿透与任意代码。
2. 渲染结果长度上限 512 字符，超出报错。
3. **按 `/` 分段清洗**：每段替换 `\ : * ? " < > |` 与控制字符为空格，压缩连续空格；
   不整体清洗，避免把目录分隔符吃掉。
4. 拒绝：空段、`..`、`.`、以 `/` 开头、绝对路径、结尾为空格或点。
5. 必须有目录层级（至少 1 个 `/`），否则提示"模板至少要有一级目录"。
6. 渲染后 `title` 为空 → 报错，避免生成 `()/Season 01/.mkv` 这类垃圾。
7. 保存时校验 + 预览时校验，同一套函数（`csx/domain/naming_template.py`），纯标准库 + jinja2，可单测。

## 5. 接入点

| 位置 | 改动 |
| --- | --- |
| `domain/naming.py` | 保留 `build_media_paths`（旧格式，供回退与旧单测）；新增 `render_media_path()` |
| `application/organize.py` | `organize_file(..., template=None)`：有模板走模板渲染，无模板走旧格式 |
| `application/organize_scan.py` | 预览与执行同源，同样接受模板 |
| `infra/naming_config.py`（新增） | 读 `naming` 分组 → 返回 `{movie, tv, variety}` 模板，缺省回落 MP 默认 |
| `infra/scheduler.py` + `api/routes/organize.py` | 与 `cloud_paths` 一起解析并下传 |
| 最终路径 | `<media_path>[/电影|电视剧]/<模板渲染结果>` —— 分层开关仍然优先套在最外层 |

## 7. 风险与兼容

| 风险 | 处理 |
| --- | --- |
| 模板写坏导致整理失败 | 保存即校验；运行时渲染失败**回退旧格式**并写日志/事件，不让任务直接失败 |
| 中文与特殊字符 | 保留中文，仅替换系统非法字符 |
| Emby 识别 | 默认模板与 MP 一致，`SxxExx` + 年份目录对 Emby 友好 |
| 已入库文件 | `library_file` 表为空，无历史数据；本批不做回溯重命名 |
| STRM | 路径由同一函数产出，自动跟随 |
| 依赖 | `pyproject.toml` 需新增 `jinja2>=3.1`（当前是间接依赖，必须显式声明） |
