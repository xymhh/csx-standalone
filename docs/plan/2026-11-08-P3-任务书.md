## 3. `domain/naming.py` 规格（自研，替代 MP TransHandler）

输入：`(media_title, media_type, year, season, episode, quality_bucket, original_ext, resource_kind)`
输出：`(folder: str, filename: str)`，均为 POSIX 风格相对路径，不含媒体库根目录。

规则（照抄旧插件已验证的行为，不要自由发挥）：

| 场景 | 目录 | 文件名 |
| --- | --- | --- |
| 剧集 | `{title} ({year})/Season {ss}` | `{title} ({year}) S{ss}E{ee}.{ext}` |
| 单集（无季）| 同上，季默认 `01` | 同上 |
| 电影 | `{title} ({year})` | `{title} ({year})}.{ext}` |
| 无年份 | `{title}` | `{title} S{ss}E{ee}.{ext}` |
| 画质标签 | — | 仅当 `quality_bucket` ∈ {`remux`,`dv`,`hdr`} 时追加 `[1080p/4K HDR/DV]` 后缀 |
|  Variety/综艺 | `{title} ({year})` | `{title} - S{ss}E{ee} ({yyyy-mm-dd}).{ext}`，无日期退回 `E{ee}` |

必做：
- 非法字符清洗 `/ \ : * ? " < > |` → 空格，合并连续空格、去首尾点与空格
- 长度上限：单段路径 200 字符
- **函数必须是纯的**：同输入同输出，不许读配置、不许访问磁盘
- `parse_episode_from_name(text) -> (season, episode)` 一并放这里（P2 的 `compat/metainfo.py` 过渡 shim 的正式版；供 organize 从转存结果文件名反推集号）

## 4. `ports/drive.py` Protocol（最小面）

```python
class DrivePort(Protocol):
    provider: str
    def check_share(self, share_url: str, password: str = "") -> ShareStatus: ...
    def list_share_files(self, share_url: str, password: str = "") -> list[ShareFile]: ...
    def transfer(self, share_url: str, target_dir: str, *,
                 file_ids: Sequence[str], password: str = "",
                 rename_map: Mapping[str, str] | None = None) -> TransferOutcome: ...
    def move(self, file_id: str, target_dir: str) -> None: ...
    def rename(self, file_id: str, new_name: str) -> None: ...
    def list_dir(self, path: str) -> list[CloudFile]: ...
```

`TransferOutcome` 是 adapter 内的 dataclass，字段至少含 `ok: bool`、`failed_files: list[str]`、`created: list[(file_id, path, size, sha1)]`、`error: str`。

**注意**：vendor 的实际方法名以 `csx/vendor/drive/{quark,p115}/share.py|provider.py|files.py` 为准，adapter 负责映射。不许为了让 adapter 好写而改 vendor。

## 5. `application/transfer.py` 规格

`execute_transfer(session, task_row, *, drives, repos, settings) -> TransferResult`

流程（每步都要落库或明确失败原因）：
1. 按 `task_row["idempotency_key"]` 取任务，用 P1 的 `TaskRepository.transition` 走 `queued → running`（状态迁移必须由 `domain/task.assert_transition` 校验，不许直接改列）
2. 取该任务的 `discovered_resource` → `DrivePort.check_share()`，**分享失效/需密码 → 直接 `dead_letter` 或 `retry_wait` 并写明 error**，不许静默
3. `list_share_files()` → 只取属于本任务的季集文件（用 `domain.naming.parse_episode_from_name` 对齐 `(season, episode)`）；识别不出的文件**跟着主集一起转**（沿用 CS 1.9.67「字幕/外挂音轨不进集覆盖但跟随媒体」的既定行为）
4. `transfer()` 到 `settings.transfer_root` 下的临时区 `CSX/_inbox`
5. 成功 → `library_file` + `media_item/season/episode` upsert（判重键用 `(media_id, season, episode)`，**绝不用文件名**）
6. `organize` 调 `domain/naming` 出的目标路径，用 `move/rename` 归位
7. 收尾：全部成功 `succeeded`；部分失败按 `domain/task.on_failure(attempt, max_attempts=3)` 决定 `retry_wait`（退避 60/120/240s，P1 已实现）或 `dead_letter`
8. **整理失败不回滚转存**（架构第 103 行）：转存成功即落库，整理单独重试

并发与限流（照架构冻结项，不许改数值）：
- 同一 `idempotency_key` 串行；全局并发 8
- 账号级令牌桶：115 = 4/min、夸克 = 8/min
- 队列满时排队不丢弃
