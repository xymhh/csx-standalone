## 1. 五大模块详细规格与文件落点

### 1.1 网盘签到 `application/checkin.py`
- **功能**：
  - 读取已配置的有效账号（`account` 表），针对 115、夸克、阿里等驱动执行每日签到
  - 记录签到结果（时间、获得积分/空间、消息、连续签到天数）
  - 支持后台调度器每日定时触发（默认每天凌晨 00:30）
  - 支持手动单次或全量触发
- **API 暴露**：
  - `POST /api/v1/checkin/run`：手动触发签到（可指定 `account_id`，默认全量）
  - `GET /api/v1/checkin/history`：获取签到历史记录列表
- **容错**：单个账号签到失败不阻断其他账号，错误记录在历史日志中。

### 1.2 STRM 导出与回写 `application/strm.py`
- **功能**：
  - 扫描所有未生成 STRM 或有更新的 `library_file` 记录
  - 按照 `settings['strm']` 配置（导出根目录 `strm_root`、URL 模板模式）生成 `.strm` 文件
  - 文件内容格式：支持网盘直链（P2 驱动已提供 `get_download_url`）、本地挂载路径（CloudDrive2/Alist 挂载模式）或独立版直链代理 URL
  - 生成成功后在 `strm_record` 表中 upsert 对应记录
  - 批量生成与清理已失效 STRM 文件
- **API 暴露**：
  - `POST /api/v1/strm/sync`：触发全量/增量 STRM 同步生成
  - `GET /api/v1/strm/records`：查询 STRM 生成记录（支持按 `library_file_id`）

### 1.3 画质阶梯与洗版升级 `domain/upgrade.py` + `application/transfer.py` 集成
- **画质等级阶梯（从高到低）**：
  `remux` (6) > `dv` (5) > `hdr` (4) > `4k` (3) > `hd` (2) > `sd` (1) > `unknown` (0)
- **洗版规则**：
  1. 订阅配置中包含 `upgrade_enabled: bool`（默认允许）
  2. 当候选资源命中某已入库的 `(media_id, season, episode)` 时：
     - 若候选画质 > 已入库画质：允许采纳转存，标记为 `is_upgrade=True`
     - 若候选画质 <= 已入库画质：判定为已有更好版本，拒绝转存并标为 `IGNORED_LOW_QUALITY`
  3. 洗版转存成功后，更新 `library_file` 记录为新文件，并触发 STRM 更新和媒体库刷新。

### 1.4 多渠道通知 `csx/adapters/notify/`
- **文件落点**：
  - `csx/adapters/notify/webhook.py`：通用 JSON Webhook 发送
  - `csx/adapters/notify/telegram.py`：Telegram Bot 发送 Markdown 消息
  - `csx/adapters/notify/feishu.py`：飞书群机器人 Webhook 发送富文本/卡片
  - `csx/adapters/notify/dispatcher.py`：统一调度器，根据 `settings['notify']` 开启的渠道并发分发
- **通知事件类型**：
  - `transfer_success`：转存整理入库成功（片名、季集、画质、耗时）
  - `upgrade_success`：洗版升级成功（原画质 → 新画质）
  - `task_dead_letter`：任务重试耗尽进入死信（错误原因、分享链接）
  - `checkin_report`：每日签到汇总（各账号成功/失败与奖励）
- **健壮性**：通知网络错误必须 catch，严禁因为通知发送失败导致转存主流程异常。

### 1.5 媒体服务器适配 `csx/adapters/media/`
- **文件落点**：
  - `csx/adapters/media/emby.py`：Emby / Jellyfin 客户端
    - 连通性测试：获取服务器信息 `GET /System/Info`
    - 媒体库刷新：触发全量或指定库刷新 `POST /Library/Refresh`
- **API 联动**：
  - `/api/v1/library/servers`：真实调用配置的 Emby 服务器测试并返回状态（不再是桩数据）
  - 转存与 STRM 成功后，由调度器/用例异步触发媒体库刷新。

## 2. 架构与边界铁律

1. `domain/upgrade.py` 必须是**纯函数/纯逻辑**，不依赖 IO、SQLAlchemy 或 vendor。
2. `adapters/notify/` 与 `adapters/media/` 只做外部 HTTP 调用，使用已安装的 `httpx` 或 `requests`。
3. `application/` 只编排用例，通过接口调用 notify 和 media，避免直接硬编码第三方细节。
4. 现有 212 个测试一行不许改，必须全部保持全绿。
