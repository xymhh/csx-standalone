#### `csx/domain/media.py`

```python
class MediaType(StrEnum):        # "tv" | "movie"
    TV = "tv"
    MOVIE = "movie"

@dataclass(frozen=True, order=True)
class EpisodeKey:
    season: int
    episode: int
    def __str__(self) -> str:    # "S01E02"（两位补零，季也补零）

@dataclass(frozen=True)
class Episode:
    key: EpisodeKey
    air_date: date | None = None
    title: str = ""

@dataclass(frozen=True)
class Season:
    number: int
    episodes: tuple[Episode, ...] = ()

@dataclass(frozen=True)
class MediaItem:
    tmdb_id: int
    type: MediaType
    title: str
    year: int | None = None
    seasons: tuple[Season, ...] = ()
```

附加要求：
- `EpisodeKey` 的排序按 `(season, episode)`；`str` 形如 `S01E02`、`S10E100`（季两位补零，集不足两位补零，超过两位按实际）。
- 所有 dataclass 必须**不可变**；集合类型一律用 `tuple` / `frozenset`，不许用 `list` / `dict` 当字段。

#### `csx/domain/subscription.py`

```python
class ScopeMode(StrEnum):        # "all" | "range" | "latest"
    ALL = "all"
    RANGE = "range"
    LATEST = "latest"

@dataclass(frozen=True)
class SubscriptionScope:
    mode: ScopeMode = ScopeMode.ALL
    seasons: tuple[int, ...] = ()          # 空 = 全部季
    from_episode: int | None = None        # 仅 RANGE 模式生效
    to_episode: int | None = None          # 仅 RANGE 模式生效
    latest_count: int = 0                  # 仅 LATEST 模式生效

    @classmethod
    def from_json(cls, raw: str | dict | None) -> SubscriptionScope
    def to_json(self) -> str
    def accepts(self, key: EpisodeKey) -> bool

def aired_episodes(seasons: Iterable[Season], today: date | None = None) -> list[EpisodeKey]
def missing_episodes(seasons, owned: Iterable[EpisodeKey], scope, today=None) -> list[EpisodeKey]
def season_progress(seasons, owned, scope, today=None) -> dict[int, tuple[int, int]]   # 季号 -> (已入库, 应入库)
```

规则（必须逐条实现，测试会照着打）：
1. **已播判定**：`air_date is None` 视为已播；否则 `air_date <= today`（`today` 默认 `date.today()`）。
2. **`accepts`**：
   - `ALL`：季过滤（`seasons` 非空则必须命中）后全收。
   - `RANGE`：季过滤命中，且 `from_episode <= episode <= to_episode`（任一端为 `None` 视为该端不设限）。
   - `LATEST`：季过滤命中，且该季已播集里**集号最大的 `latest_count` 个**被接受（`latest_count <= 0` 视为全部接受）。
3. **`missing_episodes`**：已播 ∩ scope.accepts ∩ 不在 `owned`，按 `(season, episode)` 升序、去重返回。
4. **`season_progress`**：返回出现在 `seasons` 里的每一季（即使该季 0 集也应出现，值为 `(0, 0)`），分母 = 该季已播且被 scope 接受的集数，分子 = 其中已入库的集数。
5. **`from_json` 宽容**：`None` / `""` / 非法 JSON / 缺字段 / 类型不对 → 回退 `SubscriptionScope()`（全默认），**不许抛异常**；未知字段忽略；`mode` 非法回退 `ALL`；`seasons` 里的重复值去重并升序；负数季号/集号丢弃。
6. **`to_json`**：字段固定顺序、`ensure_ascii=False`、紧凑分隔符，保证同一对象两次序列化字节一致。

#### `csx/domain/resource.py`

```python
BUCKET_ORDER: tuple[str, ...] = ("sd", "720p", "1080p", "4k")

def quality_bucket(resolution: str | int | None) -> str
def dedup_key(provider: str, share_url: str) -> str        # sha1 hex，40 位小写
def idempotency_key(provider: str, share_url: str, season: int, episode: int, bucket: str) -> str
def score(bucket: str, *, has_subtitles: bool = False, size_bytes: int | None = None) -> float
```

规则：
1. `quality_bucket`：接受 `"4K"/"2160p"/"2160"/"1080p"/"1080"/"720p"/"720"/"480p"/"360p"/None` 等，大小写不敏感、去空格；`>=2160` → `4k`，`>=1080` → `1080p`，`>=720` → `720p`，其余（含 `None`、无法解析）→ `sd`。
2. 规范化：`provider.strip().lower()`；`share_url.strip()`（**只去首尾空白，不做其他 URL 归一化**）；`bucket` 不在 `BUCKET_ORDER` 里时按 `sd` 处理。
3. `idempotency_key` 的原文严格为 `f"{provider}:{share_url}:{season}:{episode}:{bucket}"`（规范化后拼接），编码 utf-8，`sha1().hexdigest()`。
4. `score`：`BUCKET_ORDER.index(bucket) * 100 + (5.0 if has_subtitles else 0.0) + min(size_bytes/1e9, 9.0)`（`size_bytes` 为 `None` 或负数按 0 计），保留两位小数。返回值必须可解释、可复现。

#### `csx/domain/task.py`

```python
class TaskState(StrEnum):
    QUEUED, RUNNING, SUCCEEDED, RETRY_WAIT, FAILED, DEAD_LETTER, CANCELLED

class InvalidTransition(ValueError): ...

ALLOWED_TRANSITIONS: dict[TaskState, frozenset[TaskState]]
def can_transition(src: TaskState, dst: TaskState) -> bool
def assert_transition(src: TaskState, dst: TaskState) -> None      # 非法抛 InvalidTransition
def backoff_seconds(attempt: int) -> int                            # 60,120,240,480,960,1800(上限)
def next_retry_at(now: datetime, attempt: int) -> datetime
def on_failure(state: TaskState, attempt: int, max_attempts: int = 3) -> tuple[TaskState, int]
```

迁移表（必须完全一致）：

| 起点 | 允许到达 |
|---|---|
| `QUEUED` | `RUNNING`, `CANCELLED` |
| `RUNNING` | `SUCCEEDED`, `RETRY_WAIT`, `FAILED`, `CANCELLED` |
| `RETRY_WAIT` | `RUNNING`, `CANCELLED`, `DEAD_LETTER` |
| `FAILED` | `RETRY_WAIT`, `DEAD_LETTER`, `CANCELLED` |
| `DEAD_LETTER` | `QUEUED`（用户显式重试） |
| `SUCCEEDED` | 无（终态） |
| `CANCELLED` | 无（终态） |

规则：
- `backoff_seconds(attempt)`：`attempt <= 1` → 60；之后 `60 * 2**(attempt-1)`，封顶 **1800**（30 分钟）。`attempt<=0` 按 1 处理。
- `next_retry_at`：`now + timedelta(seconds=backoff_seconds(attempt))`，`now` 必须带 tz 或 naive 都支持，输出与输入同类型。
- `on_failure`：`attempt` 先 +1 得到新 attempt；`新 attempt >= max_attempts` → `(DEAD_LETTER, 新 attempt)`，否则 `(RETRY_WAIT, 新 attempt)`。

#### 迁移（alembic，程序内调用）

- `backend/alembic.ini`：最小配置，`script_location = migrations`。
- `backend/migrations/env.py`：`target_metadata = Base.metadata`；URL 从 `csx.infra.settings.settings.data_dir` 推导（与 `csx/infra/db.py` 同一套逻辑），支持被程序调用。
- `backend/migrations/versions/0001_initial_schema.py`：`revision = "0001"`，**用 `op.execute("CREATE TABLE IF NOT EXISTS ...")` 建全部 12 张表**（10 业务 + `admin_user` + `auth_session`），索引同样 `CREATE INDEX IF NOT EXISTS`；`downgrade()` 全部 `DROP TABLE IF EXISTS`。
  - 用 `IF NOT EXISTS` 的原因：线上库里 `admin_user`/`auth_session` 已由 `create_all` 建好且有数据，初次 upgrade 不能炸，也不能丢数据。

- `csx/infra/bootstrap.py`：`init_db()` 改为调用 `upgrade_to_head()`（保持函数名不变，`main.py` 的 lifespan 不用改）。

#### 仓储（ports + 实现）

- `csx/ports/repository.py`：三个 `Protocol`（`MediaRepository` / `SubscriptionRepository` / `TaskRepository`），方法签名见下，**只依赖 domain 类型 + 标准库**。
- `csx/adapters/db/__init__.py`、`csx/adapters/db/repositories.py`：SQLAlchemy 实现。

```python
class MediaRepository(Protocol):
    def upsert(self, item: MediaItem) -> int                     # 返回 media_item.id，按 tmdb_id 幂等
    def get_by_tmdb(self, tmdb_id: int) -> MediaItem | None
    def owned_episodes(self, media_id: int) -> set[EpisodeKey]   # 从 library_file join episode/season 取

class SubscriptionRepository(Protocol):
    def create(self, media_id: int, scope: SubscriptionScope, quality_pref: str = ..., source: str = "manual") -> int
    def get(self, sub_id: int) -> dict | None                    # {"id","media_id","scope","state",...}
    def list_active(self) -> list[dict]
    def set_state(self, sub_id: int, state: str) -> None

class TaskRepository(Protocol):
    def create_or_get(self, idempotency_key: str, *, subscription_id: int | None = None,
                      resource_id: int | None = None) -> tuple[int, bool]   # (task_id, created)
    def transition(self, task_id: int, dst: TaskState, *, error: str = "") -> TaskState
    def due(self, now: datetime, limit: int = 100) -> list[dict]             # state in (queued, retry_wait) and next_retry_at<=now
```

`transition` 必须走 `csx.domain.task.assert_transition`（非法迁移抛 `InvalidTransition`），并同步维护 `attempt` / `next_retry_at` / `dead_letter` / `updated_at`：`RUNNING` 时 `attempt+1`；`RETRY_WAIT` 时 `next_retry_at = next_retry_at(now, attempt)`；`DEAD_LETTER` 时 `dead_letter=1`。
