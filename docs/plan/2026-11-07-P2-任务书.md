## 1. 目标

把 CloudSubscribeX 插件的 `drive/`（7 家网盘）与 `search/`（14 个搜索源）搬进 `csx-standalone`，做到：

1. 175 个文件全部可 `import`，无任何 `app.*` 依赖
2. `DriveRegistry` 能列出 7 家、`SearchRegistry` 能列出 14 个源
3. 至少 3 个免凭证搜索源真跑通（pansou / mikan / piratebay）
4. `ruff check` 0、`pytest` 全绿

## 4. 目录布局（保持相对 import 层级不变）

```
backend/csx/vendor/
├── __init__.py
├── drive/          ← 源 drive/ 全量 57 文件
├── search/         ← 源 search/ 全量 104 文件
├── core/           ← 仅上表 10 个文件
├── utils/          ← 仅上表 4 个文件
└── compat/         ← 新写的宿主兼容层（见第 5 节）
```

`drive/` 与 `search/` 内部大量使用 `from ..core.cloud import ...`、`from ...utils.cache import ...` 这类相对 import。**保持这个层级不要重排**，否则要改 100+ 处相对路径。

## 5. import 替换表（唯一允许的代码改动）

| 原引用 | 处数 | 替换为 | 说明 |
| --- | ---: | --- | --- |
| `from app.log import logger` | 69 | `from csx.infra.log import logger` | 复用 P0 已建的 logger |
| `from app.schemas.types import ...` | 10 | `from csx.vendor.compat.schemas import ...` | 新写 shim，只保留被引用的那几个类型 |
| `from app.core.cache import ...` | 8 | `from csx.infra.cache import ...` | 新写 TTLCache 等，用标准库实现 |
| `from app.utils.string import ...` | 5 | `from csx.vendor.compat.string import ...` | 新写 shim，函数级照抄必要实现 |
| `from app.schemas import ...` | 2 | 同 `compat.schemas` | |
| `from app.helper.browser import ...` | 1 | 评估后：能删则删，不能删写 `compat.browser` 抛 `NotImplementedError` | |
| `from app.core.config import ...` | 1 | 评估后写最小 `compat.config` | |

**除上表外，不许改任何业务逻辑、函数签名、常量、正则。**

替换必须是机械的（脚本化），替换完 diff 应只有 import 行变化。

## 6. 硬约束

1. **禁止 `import app`**：CI 已有一条 grep 门禁，`git grep -n "^\(from\|import\) app"` 必须为空
2. **全部同步代码**：源里 `async def` 数量为 **0**，1620 个普通 `def`。任何在 FastAPI 路由里直接调用的地方，必须包 `await asyncio.to_thread(...)`，**不许阻塞事件循环**
3. **不许删测试**：源里若有 `tests/`，一并搬并适配 import
4. **不许改业务默认值**：限速、超时、重试次数、User-Agent 全部原样保留
5. **第三方依赖只加必要的**：`requests`、`p115client`、`cryptography`、`Crypto`、`bs4`、`numpy`、`PIL`、`qrcode` 按实际 import 加进 `pyproject.toml`，不要多装
6. **不动 P1 领域层**：`csx/domain/` 保持零框架依赖
