# 前端 UI 质感全面升级任务书（对齐 New API 视觉体系）

> 状态：待开工
> 目标：将当前简陋暗沉的前端全面重塑为 **New API / Vercel 同款的 Zinc 现代中性深灰设计系统**，大幅提升视觉精致度、信息呼吸感与操作质感。

---

## 1. 视觉设计系统规范（New API 同款 Zinc 体系）

### 1.1 核心配色方案（彻底废弃暗蓝紫，全面使用炭灰阶梯）
- **画布背景 (`bg-bg`)**：`#09090b`（Tailwind `zinc-950`）——深邃、沉浸的炭黑色
- **卡片表面 (`bg-surface`)**：`#18181b`（Tailwind `zinc-900`）——柔和有层次的深灰卡片底色
- **二级表面 (`bg-surface-2`)**：`#27272a`（Tailwind `zinc-800`）——悬停态、输入框背景、代码块
- **高亮表面 (`bg-surface-3`)**：`#3f3f46`（Tailwind `zinc-700`）
- **边界线 (`border-border`)**：`rgba(255, 255, 255, 0.08)` 或 `#27272a`（极细 1px 微分界线）
- **主要文本 (`text-fg`)**：`#fafafa`（`zinc-50`）——高对比清爽白字
- **次要文本 (`text-muted`)**：`#a1a1aa`（`zinc-400`）——柔和灰字
- **弱化文本**：`#71717a`（`zinc-500`）
- **主交互色 (`primary`)**：采用 shadcn 标志性的纯色反转（白底黑字 `bg-zinc-100 text-zinc-900 hover:bg-zinc-200 active:scale-[0.98]`），视觉极高品质
- **语义状态色（全走半透明胶囊）**：
  - 成功/入库/Ready：`text-emerald-400 bg-emerald-500/10 border-emerald-500/20`
  - 警告/等待/排队：`text-amber-400 bg-amber-500/10 border-amber-500/20`
  - 危险/缺失/失败：`text-rose-400 bg-rose-500/10 border-rose-500/20`
  - 运行/同步中：`text-sky-400 bg-sky-500/10 border-sky-500/20`

### 1.2 字体排版与微质感
- 数字全走等宽字体：`font-mono tabular-nums`
- 卡片圆角统一为 `rounded-xl`，外加极轻微内发光或微投影（`shadow-sm shadow-black/40`）
- 导航栏和顶栏带有毛玻璃质感：`backdrop-blur-md bg-zinc-950/80`

## 2. 组件升级规范 (`components/ui/`)

1. **`Button.vue`**：
   - 变体：`default`（白底黑字反转高对比）、`secondary`（深灰底 `bg-zinc-800 text-zinc-200`）、`outline`（边框微透明透明底）、`ghost`（无边框透明底）、`destructive`（红底白字）
   - 添加按压微缩放动效：`active:scale-[0.98] transition-all`
   - 最小触控高 44px
2. **`Badge.vue`**：
   - 胶囊型药丸：`rounded-full px-2.5 py-0.5 text-xs font-medium border flex items-center gap-1.5`
   - 左侧必须带有直径 6px 的呼吸指示圆点
3. **`Card.vue`**：
   - 包含优雅的结构：`CardHeader`（标题与副标题）、`CardContent`
   - 卡片与卡片之间有清晰的留白间隔（gap 4-6）
4. **`Input.vue` / `Select.vue`**：
   - 彻底废弃刺眼边框与原生粗糙控件，采用 `bg-zinc-900/80 border border-zinc-800 text-zinc-100 placeholder:text-zinc-500 focus:border-zinc-500 focus:ring-1 focus:ring-zinc-500 rounded-lg`
5. **`Table.vue`**：
   - 沉浸式极简无纵向边框表格，表头文字小号大写字母（`text-xs uppercase tracking-wider text-zinc-400 bg-zinc-900/50`），整行 hover 时微高亮（`hover:bg-zinc-800/40`）
6. **`Dialog.vue`**：
   - 毛玻璃遮罩（`backdrop-blur-md bg-black/70`），居中优雅卡片（`max-w-md w-full border border-zinc-800 bg-zinc-900 rounded-2xl p-6 shadow-2xl`）

## 3. 业务页面翻新清单

1. **全局布局 (`AppLayout` / `Sidebar` / `Topbar`)**：
   - 侧边栏：左上角极简深色 Logo、优雅的图标导航项（选中项左侧高亮条或微发光底色）、底部版本标签
   - 顶部栏：毛玻璃固定、实时 SSE 状态指示灯带呼吸光晕（绿光呼吸点）
2. **总览看板 (`DashboardPage.vue`)**：
   - 顶部 4 大指标卡（Metric Cards）：大号粗体数字、环比/说明文字、独立右上角微图标
   - 5 步流水线进度条（现代化步骤条，已完成带勾选、当前步微发光）
   - 追更健康度与执行任务分栏，结构清晰明快
3. **追更进度 (`ProgressPage.vue`)**：
   - 季集矩阵：每集改用更精致的方块格子，已入库为柔和翡翠绿、缺失为温和珊瑚红、未播为深灰
   - 单剧卡片带有进度条与封面质感
4. **系统设置 (`SettingsPage.vue`)**：
   - 6 大分组 Tab 采用现代药丸选项卡（`bg-zinc-900 p-1 rounded-xl`）
   - 表单项左右排布（左边标签与说明文字，右边输入/开关），专业后台质感
5. **候选池、任务队列、流水记录、媒体库与搜索页面**全面应用全新组件与排版。
