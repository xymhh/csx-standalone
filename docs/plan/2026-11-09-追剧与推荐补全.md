## 2. 批次划分

### 批次 A：探索推荐补到 6 榜（本批）

后端：
- `csx/adapters/media/douban.py`：`get_rank("showing"|"movie_hot"|"tv_hot")`
  - 源 `https://movie.douban.com/j/search_subjects`，`type=movie|tv`，`tag=正在热映|热门`
  - 需要浏览器 UA + `curl_cffi` impersonate（豆瓣对裸 requests 会 403）
  - 输出统一结构：`id = -douban_id`（负数，避免与 TMDB id 冲突）、`title`、`type`、`year`（从标题解析，解析不到为 null）、`vote_average = rate`、`poster_url`、`overview=""`
- `csx/adapters/media/bangumi.py`：`get_calendar()`
  - 源 `https://api.bgm.tv/calendar`（必须自定义 UA，否则 403）
  - 7 天合并去重，按 `rating.score` 降序，最多 60 条；`id = -bgm_id`
- `csx/adapters/media/anilist.py`：`get_season()`
  - GraphQL `https://graphql.anilist.co`，`season` 按当前月份推算、`seasonYear` 当前年，`sort: POPULARITY_DESC`，`perPage: 50`
  - 输出 `title` 优先 `native` 再 `romaji`；`id = -anilist_id`
- 三个适配器都要 2 小时内存缓存 + 失败返回空列表并记日志（不抛 500）
- 路由 `csx/api/routes/tmdb.py` 新增：
  - `GET /api/v1/tmdb/douban/{rank}`（rank 白名单校验，非法 400）
  - `GET /api/v1/tmdb/bangumi/calendar`
  - `GET /api/v1/tmdb/anilist/season`

前端：
- `DiscoverPage.vue` tabs 改为 6 个，顺序：流行趋势 / 正在热映 / 热门电影 / 热门剧集 / 每日放送 / 本季新番
- 顶部加筛选条：类型（全部/电影/剧集）、年份（全部/今年/近三年）、最低评分（全部/7+/8+/9+），纯前端过滤
- 「加载更多」改为一次性拉 50 条 + 前端筛选（不做无限滚动）
- 详情弹窗保持：点海报 → TMDB 匹配（用标题搜索取第一条）→ 加入追剧；无匹配时提示「TMDB 未收录，无法加入追剧」

### 批次 B：我的追剧操作闭环（下一批）

- 卡片右上角操作菜单：暂停订阅 / 恢复 / 删除（二次确认）
- 顶部状态筛选：全部 / 追更中 / 已暂停 / 已完结
- 卡片显示订阅状态徽章
- 清理冗余：`/progress`、`/baseline` 二选一合并或从路由移除
- 明确不做：「立即搜源」按钮（后端搜索执行链路未实现，做了就是假按钮）

## 3. 验收

1. 6 个 tab 全部有数据（豆瓣 3 榜 ≥ 20 条、Bangumi ≥ 30 条、AniList ≥ 30 条）
2. 筛选切换后条数变化正确，清空筛选恢复
3. 从豆瓣/AniList 条目点「加入追剧」能成功建订阅（走标题 → TMDB 匹配）
4. 任一榜单源超时/403 时页面显示空态文案，不白屏、不 500
5. `pytest` 全绿、ruff 干净、`vue-tsc` + build 通过
6. 线上真机截图核验 6 tab 与筛选
