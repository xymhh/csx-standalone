# 路径与分层配置接通（2026-11-09）

> 状态：已完成并上线（`daebf9d`，容器 `1c1b38a387ab`，镜像 `sha-daebf9d`）。

## 1. 发现的问题

用户问「网盘目录设好后，追剧与规则里的位置与分层还要怎么设」，逐层查执行链路后发现四处配置实际无效：

| 配置 | 原状 | 影响 |
| --- | --- | --- |
| 账号卡片 `transfer_path` / `media_path` | 只写库、无消费方 | 用户设的两条路径完全没被使用 |
| 设置页「网盘保存根目录」`transfer.transfer_root` | 转存读的是环境变量 `CSX_TRANSFER_ROOT` | 页面改了不生效 |
| 设置页「按媒体类型分层」 | 后端零引用 | 开关纯装饰 |
| 归档根 `library_root` | 只有环境变量，compose 未设 → 空串 | 整理后文件落到**网盘根目录** |

## 2. 决策

1. **账号级路径优先**：转存/归档都用执行账号自己的两条路径，同平台多账号互不影响。
2. 账号未填时回退运行时环境变量（`CSX_TRANSFER_ROOT/_inbox`、`CSX_LIBRARY_ROOT`），再回退 `/CSX/_inbox`、`/CSX/媒体库`。
3. 账号选择：指定账号 > 该平台已启用的主号 > 最早创建的已启用账号（停用主号会被跳过）。
4. 「按媒体类型分层」保留为用户选项：开启后在 `media_path` 下加一级 `电影/`、`电视剧/`（名字可改），默认关闭。
5. 设置页删除失效的根目录输入框，改为一句说明 + 跳转「网盘账号」的入口。

## 3. 实现位置

- `backend/csx/infra/cloud_paths.py`（新增）：`resolve_cloud_paths()` 统一解析路径与分层配置。
- `backend/csx/application/transfer.py`：`execute_transfer(..., cloud_paths=...)`，转存落 `<transfer_path>/<任务key>`，归档落 `<media_path>[/电影|电视剧]/片名 (年份)/Season xx`。
- `backend/csx/application/organize.py`：`organize_file()` 支持 `type_folder/type_movie/type_tv`，输出绝对路径。
- `backend/csx/application/organize_scan.py`：`plan_organize()` 同步支持分层，全盘整理预览与执行一致。
- `backend/csx/api/routes/organize.py`：改用当前账号的 `media_path` + 分层配置。
- `backend/csx/infra/scheduler.py`：执行任务前解析 `cloud_paths` 传入。
- `web/src/pages/SettingsPage.vue`：「网盘存储位置与分层」卡片重写（说明 + 分层开关 + 目录名）。
