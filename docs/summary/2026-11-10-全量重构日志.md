## 阶段 1：地基 —— SettingsPage 拆分 + API 按域拆分

- `pages/SettingsPage.vue` 2,751 行 → 110 行编排器 + 6 个 section 组件
  （`components/settings/`：Accounts / Drama / Charts / Sources / Playback / System）。
- `lib/api.ts`（510 行 / 83 导出）删除 → `src/api/` 按域拆 13 个文件
  （client + auth / drives / subscriptions / transfer / search / sources / settings /
  naming / telegram / organize / tmdb / autoSearch）。
- **关键保语义点**：`SettingsPage.saveAll()` 是全局耦合保存——各 section 共享状态，
  父级通过各 section 的 `defineExpose`（`collectBaseline/collectTransfer`、`collectStrm/
  collectCategory`、`collectNotify/collectAdvanced`）收集载荷；Drama 的 `saveNaming()`
  是软失败（返回错误字符串不抛错）；sources 页签分支走 `SourcesSection.saveSources()`；
  section 用 `v-show` 保持挂载，切页签不丢表单状态。以上全部原样保留。
- 保真校验：API 端点字面量集合与改造前完全一致、toast 文案一致、原模板行全部可溯。
- 验证：typecheck ✓、build ✓。

## 阶段 2：状态与数据层 —— Pinia + Vue Query

- 新依赖（仅这两个）：`pinia ^4.1.0`、`@tanstack/vue-query ^5.107.1`。
- `api/client.ts` 删除 `CustomEvent('csx:unauthorized')` 事件总线 → 改为导出的
  `setUnauthorizedHandler()` 回调注册表（client 不反向依赖 router/store，无循环依赖）；
  路由层注册回调：清 auth store + 跳登录。路由守卫改为调用 auth store 的 `fetchMe()`。
- 新增 `stores/auth.ts`（user / fetchMe / login / logout / clear）、`stores/global.ts`
  （sidebarCompact）；`main.ts` 注册 pinia 与 VueQueryPlugin，QueryClient 默认
  `retry:false, refetchOnWindowFocus:false, staleTime:0` 以保持原有加载语义。
- 全量排查 `setInterval`：真实数据轮询只有 2 处（TaskQueueCard 30 s 本地时钟、
  AccountsSection 二维码 2 s 状态轮询），其余页面的"轮询感"实际来自 SSE
  （`composables/useEvents.ts`）。迁移方式：
  - 二维码轮询 → `useQuery` + `refetchInterval: 2000`（key 含 token，状态处理逐字保留）；
  - 时钟节拍 → 抽为 `composables/useNow.ts`（全仓唯一保留的 setInterval，非数据轮询）；
  - 其余页面/组件（Dashboard / Tasks / Progress / Candidates / Baseline / Media /
    Discover / Radar / Search、TransferHistory、MediaDrawer、AccountsSection 等）
    的手写 load/refresh 全部改为 `useQuery`，手动刷新走 refetch/invalidateQueries，
    SSE 事件改为失效对应 query key。查询键按域统一：`['progress','overview']`、
    `['tasks']`、`['accounts']`、`['subscriptions']`、`['doctor']` 等，多页面共享缓存。
- 已知细微差异（DiscoverPage）：切回已访问过的页签时先显示缓存数据并后台刷新，
  不再清空转圈——其余语义不变。
- 验证：typecheck ✓、build ✓；`CustomEvent` 全仓清零；`setInterval` 仅剩 useNow 一处。
