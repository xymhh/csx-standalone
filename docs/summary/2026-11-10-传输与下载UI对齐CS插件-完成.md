## 关键决定与坑

1. **删掉假百分比**：CSX 的转存是一次性 RPC，拿不到字节级进度；只写「走到哪一步」，比编造 37% 诚实。
2. **`/tasks` 默认过滤是 bug 修复**：以前不传 `state` 就返回全部状态，「正在转存」里混进已完成历史。现在默认只返回 `queued/running/retry_wait/dead_letter`。
3. **STRM 阶段不展示**：STRM 在任务成功后由 side_effects 异步生成，任务已离开 `running`；阶段轨道止于「整理入库」，不为不存在的状态造 UI。
4. **历史分组在内存里做**：当前 4 条记录、千级以内无压力；到万级要改 SQL 聚合 + keyset 分页，已在测试文档标注为已知边界。
5. **1Panel 安全入口**：bero 面板开了安全入口，API 必须带 `Cookie: SecurityEntrance=base64("/xymhh")`（cookie 名固定，值为入口的 base64），路径前缀方式无效；不带 cookie 一律返回 `Access Temporarily Unavailable`。
6. **测试里的时间排序坑**：同秒内插入的两条记录 `updated_at` 相同，断言不能依赖顺序，改用 id 映射。
