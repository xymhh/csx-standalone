## 命名规则矩阵

- 剧集：`A/B`, 2024, S02E03 → `A B (2024)/Season 02`、`A B (2024) S02E03.mkv`。
- 无年份剧集：`Show`, S01E04 → `Show/Season 01`、`Show S01E04.mkv`。
- 电影：`Film`, 2020 → `Film (2020)`、`Film (2020).mp4`。
- 综艺有日期：`release_date=date(2024, 5, 6)` → 文件名带 `(2024-05-06)`；无日期 → `E02` 格式。日期只来自可选参数，不从标题推断。
- 质量标签：`remux→[REMUX]`、`dv→[DV]`、`hdr→[HDR]`；`sd/hd/4k/空` 不添加标签。
- 非法字符清洗与 200 字符上限均由参数化命名测试覆盖。
- `parse_episode_from_name` 有 20 个输入用例，覆盖 SxxExx、EP/E、1080p 前后缀、中文季集、日期噪音、合集计数及无法识别输入。

## FakeDrive 场景

`tests/test_application_transfer.py` 离线覆盖六类：正常单集并忽略字幕对集数判重的影响；部分转存失败进入 `retry_wait`；失效分享进入 `dead_letter`；整理失败但已落库转存文件保留且任务成功；相同幂等键第二次执行不重复转存；同一 `(media_id, season, episode)` 不因不同文件名重复入库。

## 边界与 vendor 映射

- `test_ports_purity.py` 在隔离子进程导入 domain 后确认未加载 SQLAlchemy、FastAPI、Pydantic 或 `csx.vendor`。
- `test_adapter_boundary.py` 确认 vendor import 只出现在 `csx/adapters/drive/`。
- Quark 与 P115 的分享状态都通过 vendor `check_share_status()` 返回 `ShareLinkStatus`，adapter 映射其 `is_valid/error_message`；两者没有独立 password 参数，adapter 分别将密码编码到 Quark 提取码文本 / P115 URL 的 `password` query。
- 两家 `transfer_files_batch()` 均返回成功与失败文件 ID 二元组，不直接返回目标文件路径；adapter 转存后重读目标目录，构造 `TransferOutcome.created`。
- 两家文件服务的 `move_file(item, save_path, target_name)` 与 `rename_file(path, item, target_name)` 需要 vendor 文件对象及当前目录；adapter 在转存/列目录后缓存文件对象与目录，再映射 `DrivePort` 的 ID 操作。
- P115 使用 `P115ClientManager(cookies)` 并由其组合服务提供文件查询；Quark 使用 `QuarkClient(cookie)`、`QuarkDrive` 和 provider service map。

## 未证明事项

本记录没有执行真机网盘 smoke 或真实分享转存、密码验证、跨目录移动与重命名。`tests/test_drive_smoke.py` 仅提供 `@pytest.mark.net` 测试入口；主 agent 配置真实 cookie 与分享链接后再运行。离线 FakeDrive 结果不能证明服务端对真实账号的响应行为。
