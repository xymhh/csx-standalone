# 功能补全第 2 批验收记录：302 直链播放重定向 + 网盘全盘整理 + 重复版本查重

> 状态：全部完成并已通过实测验收。

## 1. 交付功能模块

1. **302 直链播放服务 (`csx/api/routes/stream.py`)**：
   - 公开直链端点 `GET /api/v1/stream/redirect`：接收 `file_id`，查询 `library_file` 记录，调用驱动换取网盘高速直链，返回 HTTP 302 Found 重定向到网盘原画流地址，彻底解放服务器带宽。
   - 内存 TTL LRU 缓存：TTL 45 分钟，上限 512 条，按 `(file_id, user_agent)` 联合签名缓存，防止播放器拉取时触发网盘风控。
   - `application/strm.py` 联动：全面适配直链 URL 输出，为 Emby / Jellyfin 提供即开即播能力。

2. **网盘全盘/暂存区整理 (`csx/application/organize_scan.py` & `csx/api/routes/organize.py`)**：
   - 扫描预览 `POST /api/v1/organize/scan`：指定网盘与源目录，遍历视频文件，用 `domain/naming.py` 智能识别片名季集，给出标准归位目标路径。
   - 批量执行 `POST /api/v1/organize/execute`：批量调用网盘 `move` 和 `rename` 归位，更新/插入 `library_file`，并自动清理多级空目录。

3. **重复文件/多版本查重与清理 (`csx/api/routes/duplicate.py`)**：
   - 查重接口 `GET /api/v1/library/duplicates`：按 `(media_id, season, episode)` 聚合多版本，依画质阶梯（`remux > dv > hdr > 4k > hd > sd`）智能高亮推荐保留项，其余标为建议清理。
   - 清理接口 `POST /api/v1/library/duplicates/clean`：一键清理冗余 `library_file` 与关联 STRM，并同步调用网盘驱动删除文件。

4. **媒体库前端多视图管理 (`web/src/pages/MediaPage.vue`)**：
   - 选项卡切换：**已入库文件**（带画质徽章与一键复制 302 播放直链）/ **网盘全盘整理**（支持目录树点选、扫描预览与一键归位）/ **多版本查重**（一键清理冗余释放网盘空间）。
