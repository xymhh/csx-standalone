# 功能对齐第 3 批验收：Telegram 频道消息抓链

## 实现内容

- 新增纯领域解析器 `csx/domain/tg.py`：识别 115、夸克、阿里、百度、天翼、123 云盘、UC、蓝奏云和文叔叔分享链接，提取临近密码，并从消息前两行清理片名、季号和集号。领域模块只依赖标准库和 `csx.domain.naming`。
- 新增 `csx/application/tg_monitor.py`：按活跃订阅标题包含/相似度匹配，检查订阅范围和媒体库缺集状态；为命中的分享创建高评分 `discovered` 候选。自动转存开启时用资源幂等键创建 `queued` 任务。
- 新增 `POST /api/v1/tg/parse`、`POST /api/v1/tg/ingest`、`GET /api/v1/tg/status`，统一使用 API 包络并受全局登录保护。频道配置复用 `sources.tgchannels`，ingest 未传 `auto_transfer` 时读取该设置，默认为开启。
- Radar 页新增频道列表、监控/自动转存配置和消息解析测试器，展示片名、季集、分享链接、提取码及订阅匹配结果。
- 新增离线测试覆盖复杂排版、多个网盘链接、外部链接、密码、噪音标题、订阅匹配、候选与任务创建、自动转存关闭和状态配置。

## 运行范围说明

本批接口接受 Telegram 消息并完成解析、匹配、候选入库和任务排队。任务书没有定义 Telegram 登录凭据、Bot Token/会话格式或长连接监听器生命周期，因此这里没有自行引入主动 Telegram 网络监听；频道消息需由配置好的 Telegram 接入端调用 `/api/v1/tg/ingest`。链接解析支持多种网盘，但当前独立版 DrivePort 只有 115 与夸克实现，阿里、百度等链接会创建候选和队列任务，实际转存仍需相应 DrivePort。
