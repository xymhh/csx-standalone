# 功能补全第 3 批验收记录：115 云端离线下载管理 + 跨盘转存通道

> 状态：全部完成并已通过实测验收。

## 1. 交付功能模块

1. **115 云端离线下载管理服务 (`csx/api/routes/offline.py` & `csx/adapters/drive/p115.py`)**：
   - 任务列表 `GET /api/v1/drives/offline/tasks?account_id=xxx`：直接查询当前 115 账号下的云端离线任务列表，包含任务名称、进度百分比、文件大小、状态、添加时间。
   - 添加磁力/下载链接 `POST /api/v1/drives/offline/add`：支持直接提交 `magnet:?xt=...` 或 HTTP/FTP 下载地址，调用 115 官方云端离线 API 建立下载任务。
   - 删除任务 `POST /api/v1/drives/offline/delete`：支持批量删除指定 info_hash 的离线任务。
   - 权限与安全：端点受全局认证保护，对非 115 账号请求返回友好提示 `OFFLINE_NOT_SUPPORTED`。

2. **转存与离线任务前端管理台 (`web/src/pages/TasksPage.vue`)**：
   - 选项卡切换：**本地转存队列**（执行中任务监控）/ **115 云端离线任务**（磁力直下、进度条展示、删除与刷新）。
   - 顶部配有 **「+ 添加磁力离线」** 弹窗，支持粘贴任意磁力链接一键提交。
