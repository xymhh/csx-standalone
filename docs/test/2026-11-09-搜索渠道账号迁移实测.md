## 4. 待办

1. 盘链：在浏览器里用该账号登录一次并同意用户协议（15 秒阅读门槛是站点侧限制）。

4. 聚影 / 蜗牛：需要先注册账号。
5. 在线文档：需要真实文档 URL 与网盘类型。
