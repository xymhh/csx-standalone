## 1. 本次交付

| 层 | 改动 | 位置 |
| --- | --- | --- |
| 端口 | 新增 `create_directory(parent_id, name)` | `backend/csx/ports/drive.py` |
| 115 | `makedir(contain_dir=True)`，同名目录复用、不重复创建 | `backend/csx/vendor/drive/p115/files.py` |

| API | `POST /api/v1/drives/{account_id}/folders` | `backend/csx/api/routes/drives.py` |
| API | `GET /api/v1/drives/{account_id}/folders` 支持 `parent_path` | 同上 |
| 前端 | 弹窗内联新建、回车创建、Esc 取消、创建后刷新并选中 | `web/src/components/dialogs/DirectorySelectDialog.vue` |

顺带修掉一个真实缺陷：`GET /folders` 每次请求都会新建适配器实例，导致适配器内的
`_directory_paths` 为空，二级及以下目录返回的 `path` 一律退化为 `/xxx`（选中后存的是错误路径）。
现在前端把 `parent_path` 一并传回，服务端统一拼接。
