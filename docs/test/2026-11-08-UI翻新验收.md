# UI 翻新验收记录

## 视觉系统

主题由原先带蓝紫色相的暗色 OKLCH 配色改为中性 Zinc 阶梯：画布 `#09090b`（zinc-950）、卡片 `#18181b`（zinc-900）、次级表面 `#27272a`（zinc-800）、高亮表面 `#3f3f46`（zinc-700）、文字 `#fafafa`、次级文字 `#a1a1aa`。边框使用低对比白色透明度；主按钮改为浅色底深色字的反转样式。

状态采用 emerald、amber、rose、sky 语义 tokens，并统一为带 6px 呼吸点的胶囊 Badge。数字使用等宽与 tabular-nums。导航和顶栏采用半透明背景与 backdrop blur，输入、选择、表格和弹窗统一深色表面与柔和聚焦状态。

## 升级的组件与页面

- UI 组件：Button（五种变体）、Badge、Card / CardHeader / CardTitle / CardDescription / CardContent、Input、Select、Table、Dialog、Tabs、Switch、Toast。
- 布局和领域组件：AppLayout、Sidebar、Topbar、PipelineTracker、EpisodeMatrix、MediaCard、CandidateCard、TaskRow。
- 十个业务页：Dashboard、Progress、Baseline、Radar、Candidates、Tasks、History、Media、Settings、Search。Dashboard 使用四项指标卡和五步流水线；Progress 使用方形季集矩阵；Settings 改为左右分栏并继续使用原有分组保存 API。
- 保留原有路由、API 调用、SSE 状态订阅和页面操作；侧栏折叠状态与主内容区宽度同步，移动端抽屉保留完整导航标签。

## 实测门禁

在 `web/` 下运行：

```text
$ npm run typecheck
> vue-tsc --noEmit

# exit 0，无类型错误
```

```text
$ npm run build
> vite build
✓ 2134 modules transformed.
✓ built in 3.09s
```

Build 生成 `dist/index.html` 与 `dist/assets`。本次仅执行任务书要求的 typecheck 和 build 门禁。
