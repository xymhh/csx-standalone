## 3. 我在验收中另外审计出并修掉的 4 个问题

| # | 问题 | 后果 | 修法 |
|---|---|---|---|
| 1 | `missing_episodes` / `season_progress` 多次迭代 `seasons` 参数 | 传生成器时结果为空（规格声明是 `Iterable`） | 入口 `tuple(seasons)`；补 2 个生成器用例 |
| 2 | `TaskRepository.due()` 用 `next_retry_at <= now` | 新建任务 `next_retry_at` 为 NULL，**永远捞不到**，调度器停摆 | 改成 `next_retry_at IS NULL OR next_retry_at <= now`，补 1 个用例 |
| 3 | `script_location` 用 `Path(__file__).parents[2]` | 镜像里 `pip install .` 后 `__file__` 在 site-packages，`/app/migrations` 找不到 → 容器启动即崩 | 改成多候选（`CSX_MIGRATIONS_DIR` → 源码树 → cwd → `/app`），找不到明确抛错 |
| 4 | `quality_bucket` 里 `except Exception` 兜底 + 一条测试把「未知 bucket ≠ sd」当成期望 | 与规格相反（规格：未知 bucket 按 `sd`） | 删掉 broad except；测试改为断言相等 |
