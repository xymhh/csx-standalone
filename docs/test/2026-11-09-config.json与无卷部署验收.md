## 4. 踩坑

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| compose 已删 volume，容器仍挂 `/data` | Dockerfile 里 `ENV CSX_DATA_DIR=/data` 优先级高于 config.json | 删掉该 ENV（及 `CSX_WEB_DIST`） |
| 重建后出现新的匿名卷挂 `/data` | Dockerfile `VOLUME ["/data"]` | 删掉 VOLUME 声明，重建镜像 |
| `files/save` 报「目标路径不存在」 | 1Panel save 不自动建父目录 | 改用 `files/upload`（自动建目录） |

## 6. 镜像 tag

- 生产 compose 用 `latest`（`docker/metadata-action` 在默认分支上打 `latest` + `sha-<短sha>` 两个 tag）
- 回滚时把 image 改成对应的 `sha-xxxxxxx` 再 `up`
- 每次 `compose up` 前若需强制更新：先 `pull` 再 `up`；不拉则沿用本地已有的 latest 层
