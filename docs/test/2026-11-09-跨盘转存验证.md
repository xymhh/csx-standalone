### 发现的 bug（已修，commit 8995df7）

`115 移动文件失败: <id>（文件未登记）` —— `P115DriveAdapter.move/rename` 依赖进程内 `_known`
缓存（只有同盘 `transfer()` 会登记）。跨盘中继走 vendor 的 `TargetWriter` 写盘，文件 id
从未登记，导致整理阶段第一步 `drive.move()` 直接抛错；而旧逻辑「整理失败仍标 succeeded」，
任务显示成功但库里只有 `/CSX/转存/...` 的中转路径（= 长期「转存成功但媒体库空」的根因）。

修法三处：
1. `adapters/drive/p115.py` 新增 `remember(file_id, item, directory)`；
2. `adapters/drive/cross_relay.py` 中继返回值带回落盘 `CloudFile`；
3. `application/transfer.py` 中继后调用 `target_drive.remember(...)`；整理失败改为
   `retry_wait` 并写日志（不再默默 succeeded）。

存量数据修复：对任务 4 手动重放整理，落盘
`/CSX/媒体库/电影/人生真美丽 (2022)/人生真美丽 (2022).mp4`，库记录 id=4 path 已同步。
