## 3. 发现并修复的回归（本次重构引入）

**现象**：设置页切到任意页签，`网盘账号` 与 `播放与整理` 两个区块始终显示，页签等于失效；其余 4 个 section 正常。

**定位过程**：浏览器实测 6 个页签，用 `div.space-y-5` 可见性计数 → 每次可见集合恒含 index 0 与 3。

**根因**：`AccountsSection.vue` / `PlaybackSection.vue` 模板根节点不唯一（主 div + 扫码 Dialog + 目录选择弹窗）。Vue 对**多根节点组件**无法继承属性，`SettingsPage` 上的 `v-show` 被静默丢弃，因此永远显示。

**修法**：两个弹窗移进主 div 内（`Dialog` 内部 `Teleport to="body"`，不影响布局），恢复唯一根节点；顺带对这两个文件跑 prettier。
