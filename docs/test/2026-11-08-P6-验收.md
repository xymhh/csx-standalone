# P6 验收记录

## 实现模块

- `csx/domain/upgrade.py`：质量阶梯 `remux > dv > hdr > 4k > hd > sd > unknown`，纯函数比较与 `upgrade_enabled` 洗版决策。
- `csx/application/checkin.py`：按账号逐项执行签到、统一归一结果并持久记录；单账号异常写历史后继续。`TaskScheduler` 每日按服务器本地时间 00:30 触发，API 支持指定账号或全量执行。
- `csx/application/strm.py`：根据 `strm_root` 生成 STRM，支持本地挂载路径、模板/代理 URL 与网盘直链；按 `library_file_id` upsert，支持清理失效记录。新生成 `library_file.provider` 供直链 adapter 选择网盘。
- `csx/adapters/notify/`：Webhook JSON、Telegram Markdown、飞书交互卡片；dispatcher 并发发送、逐渠道捕获异常，主任务之后在后台触发。
- `csx/adapters/media/emby.py`：Emby/Jellyfin `GET /System/Info` 探测和 `POST /Library/Refresh`；`/api/v1/library/servers` 返回真实探测状态。
- API：`POST /api/v1/checkin/run`、`GET /api/v1/checkin/history`、`POST /api/v1/strm/sync`、`GET /api/v1/strm/records`；所有路由经 `ok` 或标准 HTTP 错误包络。
- 迁移 `0004` 新增 `checkin_record`；迁移 `0005` 为 `library_file` 增加可空 provider 字段。P2 vendor 文件没有改动。

## 配置键

- STRM：`strm.strm_root`、`strm.mode`、`strm.local_mount_root`、`strm.url_template`。
- 媒体服务器：`advanced.emby_url`、`advanced.emby_api_key`、`advanced.jellyfin_url`、`advanced.jellyfin_api_key`。
- 夸克签到复用 vendor 已有配置名 `sources.quark_checkin_url`；115 使用账号凭据。
- 通知配置：`notify.channels` 对象，渠道键为 `webhook`、`telegram`、`feishu`，各渠道配置含 `enabled` 及对应 URL/token/chat_id。

P4 当前账号 adapter 支持 115 与夸克；P2 vendor 未提供阿里云盘签到方法，本阶段不会伪造 AliPan 签到成功记录。
