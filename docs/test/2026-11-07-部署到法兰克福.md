## 三、部署手法（无 SSH，全程 1Panel v2 API）

1. 本地打包：`tar czf csx-standalone.tar.gz --exclude={.git,node_modules,dist,__pycache__}`
2. 上传：`POST /api/v2/files/upload`，**`path` 必须放在 multipart form 里**（放 query 会报 `参数错误: error paths in request`）
3. 解压：**`files/decompress` 返回 success 但什么都不解**（老坑）→ 用一次性 compose 跑 `redis:7.4-alpine` + `tar xzf`
4. 建项目：`POST /api/v2/containers/compose` `{name, from:"edit", file:"<yaml 全文>"}`
5. 构建启动：`POST /api/v2/containers/compose/operate` `{name, operation:"up", path:".../docker-compose.yml"}`（**字段名是 `operation` 不是 `operate`**）
6. 清理：容器 `operation:"remove"`；compose 记录 `operation:"delete"`

## 四、坑

- `files/search` 要列子项必须 `expand:true`，否则 `items` 为 `null`
- `containers/compose/operate` 不带 `path` 会报 `no configuration file provided`
- compose 里的 `build.context` 必须写**绝对路径**（1Panel 的 workdir 固定，相对路径会指错）
- 容器名与 compose 项目名一致时，`container_name` 也要显式写，避免随机后缀
