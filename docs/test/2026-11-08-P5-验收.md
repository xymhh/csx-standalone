# P5 前端验收记录

## 页面与路由

- `/` Dashboard：流水线、媒体缺集、任务与 Doctor 诊断。
- `/progress` Progress：媒体进度卡片/列表切换、按季集矩阵展开。
- `/baseline` Baseline：订阅查询、新建、启停、立即同步、删除。
- `/radar` Radar：来源配置、服务连通性测试、Doctor 检查。
- `/candidates` Candidates：待处理候选、采纳转存、忽略。
- `/tasks` Tasks：队列状态、重试、取消；SSE `task_status` 后重新取任务数据。
- `/history` History：终态任务、来源筛选、失败任务批量重试。
- `/media` Media：文件列表、大小和画质统计、Emby/Jellyfin 配置状态。
- `/settings` Settings：6 个配置分组 JSON 编辑保存；账号增删改、测试及凭据脱敏显示。
- `/search` Search：搜索输入与来源配置查看。P4 当前没有手动搜索或候选创建 API；页面在提交搜索时明确提示后端接口暂不可用，不展示模拟结果。
- `/login` 保留原有登录与认证逻辑。

## 核心组件

- Layout：`AppLayout`、`Sidebar`、`Topbar`（响应式抽屉、桌面收拢、SSE 状态灯）。
- UI：Button、Input、Card、CardHeader、CardTitle、CardContent、Badge、Dialog/Modal、Tabs、Table、Switch、Toast。
- Domain：PipelineTracker、MediaCard、EpisodeMatrix、TaskRow、CandidateCard。
- Composables：单例 SSE `useEvents`、`useToast`。

颜色仅使用 `theme.css` 语义化 tokens；交互按钮/输入/开关和导航触控目标至少 44px。前端没有新增 CSS 裸色值。
