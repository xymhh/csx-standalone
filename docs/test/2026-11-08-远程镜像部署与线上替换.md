## 1. 核心变更

根据用户要求完成三项架构与部署收敛：
1. **远程镜像**：不再在法兰克福服务器上跑本地 `docker build`。由 GitHub Actions 在云端自动构建并发布到 GitHub Container Registry（`ghcr.io/xymhh/csx-standalone:latest`）。
2. **零端口映射**：compose 文件不配置任何宿主 `ports:` 映射。
3. **MP 同款网络模式**：直接挂载 `1panel-network` 外部网络（`external: true`），与 MoviePilot 完全同构，由内部 Cloudflare Tunnel（`berohost`）反代 `http://csx-standalone:8000` 提供公网访问。
