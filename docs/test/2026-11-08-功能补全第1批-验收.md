# 功能补全第 1 批验收

## 实现内容

- 网盘目录树：`DrivePort.list_directories()`，115 / 夸克适配器提供目录 ID、路径及子目录标记；新增 `GET /api/v1/drives/{account_id}/folders`。Settings 的网盘转存目录和本地挂载根路径可通过目录树选择。
- 手动转存：新增分享解析与排队接口 `POST /api/v1/drives/share/inspect`、`POST /api/v1/drives/share/transfer`。快捷转存弹窗支持粘贴链接、填写提取码、勾选文件、选账号和目标目录。
- 手动任务独立存放于 `manual_transfer`，避免伪造订阅或写入媒体库。调度器按选定账号执行转存并把文件直接放到选定目标目录；关联媒体 ID 为可选元数据，不触发媒体整理。
- 剧集详情：`GET /api/v1/progress/{media_id}` 返回媒体类型、年份、简介、海报，以及每集的库内文件 ID、路径、大小、画质桶和入库时间。新增 `MediaDrawer.vue`，可从进度页和控制台打开。
