## 2. 真机操作记录

### 2.1 首页加载被系统自检拖死（本次发现并修复的真实故障）

- 现象：部署后首页「已关注 0 部影视」「追剧清单 0」，但 `GET /api/v1/progress` 直接返回 4 条。
- 根因：`load()` 用 `Promise.all([doctorApi.diagnose(), progressApi.overview(), tasksApi.list()])`，`/api/v1/doctor` 对每个网盘账号串行 `drive.list_dir("/")`，115 / 夸克接口挂起 → 整个 Promise 永不 settle → 三个数据全部丢弃。
- 实测：修复前 `GET /api/v1/doctor` 60s 超时无响应；修复后 11.1s 返回，其中两个账号报「探测超时，网盘接口无响应」。
- 修法：
  1. 后端 `diagnose()` 改为 `ThreadPoolExecutor(max_workers=min(4, n))` 并行探测，单账号 `future.result(timeout=5)` 超时即返回占位结果，`shutdown(wait=False)` 不阻塞响应（提交 9f830bf）。
  2. 前端 `load()` 三请求互不等待：追剧清单立即渲染，自检与任务列表后台补齐（提交 3818927）。
- 结论：首页从「12 秒以上仍空」变为「约 1 秒出清单」。
